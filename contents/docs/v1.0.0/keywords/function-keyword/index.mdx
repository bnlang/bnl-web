# <I18nEnglish>`function` keyword</I18nEnglish>
# <I18nBangla>`ফাংশন` কীওয়ার্ড</I18nBangla>


<I18nEnglish>
`function` introduces a function. Functions are first-class values — you can store them in variables, pass them as arguments, and return them from other functions. The Bangla form `ফাংশন` is equivalent.

## Declaration

```bnl
function add(a, b) {
    return a + b;
}

print(add(2, 3));   // 5
```

## Expression (anonymous function)

```bnl
var double = function (n) { return n * 2; };
print(double(7));   // 14
```

You'll see this form a lot when passing callbacks:

```bnl
import "io" as io;

io.read_file_async("notes.txt", function (err, data) {
    if (err != null) { print("read err:", err); return; }
    print("got", data.byte_length, "bytes");
});
```

## Fixed arity

Functions take **exactly** the declared number of arguments. There are no defaults, no overloads, no rest parameters, no `arguments` object.

```bnl
function greet(name) {
    return "Hi, " + name;
}

greet("Alice");        // ok
// greet();            // error: expects 1 argument, got 0
// greet("Alice", 1);  // error: expects 1 argument, got 2
```

If you need different shapes, split into separately-named functions:

```bnl
function greet(name)               { return "Hi, " + name; }
function greet_formal(title, name) { return title + " " + name; }
```

## Closures

Inner functions capture outer variables by reference:

```bnl
function make_counter() {
    var n = 0;
    return function () {
        n = n + 1;
        return n;
    };
}

var c = make_counter();
print(c());   // 1
print(c());   // 2
```

## Return value

`return <expr>;` returns the expression's value. A bare `return;` (or falling off the end) returns `null`.

See [`return`](/en/docs/v1.0.0/keywords/return-keyword) for details.

## Bangla form

```bnl
ফাংশন যোগ(a, b) {
    ফেরত a + b;
}

print(যোগ(2, 3));   // 5
```
</I18nEnglish>

<I18nBangla>
`function` একটি ফাংশন পরিচয় করায়। ফাংশন first-class মান — আপনি এদের ভ্যারিয়েবলে রাখতে পারেন, আর্গুমেন্ট হিসেবে পাস করতে পারেন, এবং অন্য ফাংশন থেকে ফেরত দিতে পারেন। বাংলা রূপ `ফাংশন` সমার্থক।

## ডিক্লেয়ারেশন

```bnl
function add(a, b) {
    return a + b;
}

print(add(2, 3));   // 5
```

## এক্সপ্রেশন (anonymous function)

```bnl
var double = function (n) { return n * 2; };
print(double(7));   // 14
```

কলব্যাক পাস করার সময় এই রূপটি প্রচুর দেখবেন:

```bnl
import "io" as io;

io.read_file_async("notes.txt", function (err, data) {
    if (err != null) { print("read err:", err); return; }
    print("got", data.byte_length, "bytes");
});
```

## ফিক্সড অ্যারিটি

ফাংশন **ঠিক** ডিক্লেয়ার্ড সংখ্যক আর্গুমেন্ট নেয়। কোনো ডিফল্ট নেই, কোনো ওভারলোড নেই, কোনো rest parameter নেই, কোনো `arguments` অবজেক্ট নেই।

```bnl
function greet(name) {
    return "Hi, " + name;
}

greet("Alice");        // ok
// greet();            // error: 1 argument expected, got 0
// greet("Alice", 1);  // error: 1 argument expected, got 2
```

ভিন্ন শেপ দরকার হলে আলাদা নামের ফাংশনে ভাগ করুন:

```bnl
function greet(name)               { return "Hi, " + name; }
function greet_formal(title, name) { return title + " " + name; }
```

## ক্লোজার

ইনার ফাংশন আউটার ভ্যারিয়েবল রেফারেন্স দিয়ে ক্যাপচার করে:

```bnl
function make_counter() {
    var n = 0;
    return function () {
        n = n + 1;
        return n;
    };
}

var c = make_counter();
print(c());   // 1
print(c());   // 2
```

## রিটার্ন ভ্যালু

`return <expr>;` এক্সপ্রেশনের মান ফেরত দেয়। খালি `return;` (অথবা শেষ পর্যন্ত পৌঁছানো) `null` ফেরত দেয়।

বিস্তারিত [`return`](/bn/docs/v1.0.0/keywords/return-keyword) দেখুন।
