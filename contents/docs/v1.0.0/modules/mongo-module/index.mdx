# <I18nEnglish>`mongo` module</I18nEnglish>
# <I18nBangla>`mongo` মডিউল</I18nBangla>


<I18nEnglish>
MongoDB client backed by mongo-c-driver. Connect with a URI, drill down to `db.collection`, and CRUD with plain maps.

```bnl
import "mongo" as mongo;

var client = mongo.connect("mongodb://localhost:27017");
var coll   = client.db("myapp").collection("users");

coll.insert_one({ name: "Alice", roles: ["admin"] });
var alice = coll.find_one({ name: "Alice" });
print(alice.roles[0]);                 // admin

coll.update_one({ name: "Alice" }, { roles: ["admin", "editor"] });
coll.delete_one({ name: "Alice" });

client.close();
```

## Module API

| Function | Description |
|---|---|
| `mongo.connect(uri)` → client | Parse and connect. URI like `mongodb://user:pass@host:port/?authSource=...`. |
| `mongo.version()` → string | mongo-c-driver client version. |

## Client / db / collection

| Step | Description |
|---|---|
| `client.db(name)` | Pick a database. Returns `{collection(name), drop(), ...}`. |
| `client.collection(db_name, coll_name)` | Shortcut for `client.db(d).collection(c)`. |
| `client.close()` | Drop the connection. |
| `db.collection(name)` | Pick a collection. |
| `db.drop()` | Drop the whole database. |

## Collection methods

| Method | Description |
|---|---|
| `coll.insert_one(doc)` | Insert. |
| `coll.find_one(filter)` → map \| null | First matching doc. |
| `coll.update_one(filter, update)` | Apply `$set`-style update. |
| `coll.delete_one(filter)` | |
| `coll.drop()` | Drop the collection. |
