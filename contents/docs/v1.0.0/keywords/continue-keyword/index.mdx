# <I18nEnglish>`continue` keyword</I18nEnglish>
# <I18nBangla>`চলুন` কীওয়ার্ড</I18nBangla>


<I18nEnglish>
`continue;` skips the rest of the current loop iteration and re-evaluates the loop condition (or moves to the next item for `for ... of`). Bangla form: `চলুন;`.

Note: `continue` only applies to **loops**. Inside a `switch` it passes through to the enclosing loop.

## Syntax

```bnl
continue;
```

## Examples

Skip even numbers:

```bnl
var i = 0;
while (i < 6) {
    i = i + 1;
    if (i % 2 == 0) { continue; }
    print(i);
}
// 1
// 3
// 5
```

In a C-style `for`, the update clause **still runs** before the next iteration:

```bnl
for (var k = 0; k < 5; k = k + 1) {
    if (k == 2) { continue; }
    print(k);
}
// 0
// 1
// 3
// 4
```

In `for ... of`, the loop advances to the next item:

```bnl
for (var name of ["alice", "_skip", "bob"]) {
    if (name.starts_with("_")) { continue; }
    print(name);
}
// alice
// bob
```

## continue inside a switch

`continue` does **not** match the enclosing `switch`. It propagates outward to the next enclosing loop:

```bnl
for (var n of [1, 2, 3]) {
    switch (n) {
        case 2: { continue; }    // skips n==2 in the outer for-of
        default: { print(n); }
    }
}
// 1
// 3
```

## Bangla form

```bnl
যতক্ষণ (p < 5) {
    p = p + 1;
    যদি (p == 2) { চলুন; }
    print(p);
}
```

<I18nBangla>
`continue;` কারেন্ট loop iteration-এর বাকি অংশ skip করে এবং loop condition পুনরায় মূল্যায়ন করে (অথবা `for ... of`-এর জন্য পরের item-এ যায়)। বাংলা রূপ: `চলুন;`।

নোট: `continue` শুধু **loops**-এ প্রযোজ্য। একটি `switch`-এর ভেতরে এটি enclosing loop-এ পাস হয়ে যায়।

## সিনট্যাক্স

```bnl
continue;
```

## উদাহরণ

জোড় সংখ্যা skip:

```bnl
var i = 0;
while (i < 6) {
    i = i + 1;
    if (i % 2 == 0) { continue; }
    print(i);
}
// 1
// 3
// 5
```

C-স্টাইল `for`-এ, update clause পরবর্তী iteration-এর আগে **still চলে**:

```bnl
for (var k = 0; k < 5; k = k + 1) {
    if (k == 2) { continue; }
    print(k);
}
// 0
// 1
// 3
// 4
```

## switch-এর ভেতরে continue

`continue` enclosing `switch`-এর সাথে **মেলে না**। এটি পরবর্তী enclosing loop-এ propagate হয়:

```bnl
for (var n of [1, 2, 3]) {
    switch (n) {
        case 2: { continue; }    // outer for-of-এ n==2 skip
        default: { print(n); }
    }
}
// 1
// 3
```

```bnl
যতক্ষণ (p < 5) {
    p = p + 1;
    যদি (p == 2) { চলুন; }
    print(p);
}
```
