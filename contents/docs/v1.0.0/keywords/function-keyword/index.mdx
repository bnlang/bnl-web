# <I18nEnglish>`function` keyword</I18nEnglish>
# <I18nBangla>`ফাংশন` কীওয়ার্ড</I18nBangla>


<I18nEnglish>
`function` introduces a function. Functions are first-class values — you can store them in variables, pass them as arguments, and return them from other functions. The Bangla form `ফাংশন` is equivalent.

## Declaration

```bnl
function add(a, b) {
    return a + b;
}

print(add(2, 3));   // 5
```

## Expression (anonymous function)

```bnl
var double = function (n) { return n * 2; };
print(double(7));   // 14
```

You'll see this form a lot when passing callbacks or `.next` / `.fail` handlers:

```bnl
import "request" as r;

r.get("https://example.com/data")
    .next(function (resp) { print(resp.body); })
    .fail(function (e)    { print("err:", e); });
```

## Fixed arity (with optional defaults)

Functions take a fixed number of arguments. There are no overloads, no rest parameters, no `arguments` object. Parameters at the *end* of the list may have **default values**; those become optional at the call site.

```bnl
function greet(name, greeting = "Hi") {
    return greeting + ", " + name;
}

greet("Alice");           // "Hi, Alice"
greet("Alice", "Hello");  // "Hello, Alice"
// greet();               // error: expects 1 to 2 arguments, got 0
// greet("Alice", "x", "y"); // error: expects 1 to 2 arguments, got 3
```

Default rules:

- Defaults must come at the **end** of the parameter list. `function bad(a = 1, b) { ... }` is a parse error.
- Default expressions are evaluated **lazily, on each call**, in the function's local environment — so a later default can reference earlier params:

  ```bnl
  function range(start, end = start + 10) {
      return [start, end];
  }
  range(0);     // [0, 10]
  range(100);   // [100, 110]
  ```

For genuinely different shapes (different return type, different intent), still split into separately-named functions:

```bnl
function greet(name)               { return "Hi, " + name; }
function greet_formal(title, name) { return title + " " + name; }
```

## Closures

Inner functions capture outer variables by reference:

```bnl
function make_counter() {
    var n = 0;
    return function () {
        n = n + 1;
        return n;
    };
}

var c = make_counter();
print(c());   // 1
print(c());   // 2
```

## Return value

`return <expr>;` returns the expression's value. A bare `return;` (or falling off the end) returns `null`.

See [`return`](/en/docs/v1.0.0/keywords/return-keyword) for details.

## Bangla form

```bnl
ফাংশন যোগ(a, b) {
    ফেরত a + b;
}

print(যোগ(2, 3));   // 5
```
</I18nEnglish>

<I18nBangla>
`function` একটি ফাংশন পরিচয় করায়। ফাংশন first-class মান — আপনি এদের ভ্যারিয়েবলে রাখতে পারেন, আর্গুমেন্ট হিসেবে পাস করতে পারেন, এবং অন্য ফাংশন থেকে ফেরত দিতে পারেন। বাংলা রূপ `ফাংশন` সমার্থক।

## ডিক্লেয়ারেশন

```bnl
function add(a, b) {
    return a + b;
}

print(add(2, 3));   // 5
```

## এক্সপ্রেশন (anonymous function)

```bnl
var double = function (n) { return n * 2; };
print(double(7));   // 14
```

কলব্যাক বা `.next` / `.fail` handler পাস করার সময় এই রূপটি প্রচুর দেখবেন:

```bnl
import "request" as r;

r.get("https://example.com/data")
    .next(function (resp) { print(resp.body); })
    .fail(function (e)    { print("err:", e); });
```

## ফিক্সড অ্যারিটি (optional default-সহ)

ফাংশন নির্দিষ্ট সংখ্যক আর্গুমেন্ট নেয়। কোনো overload, rest parameter বা `arguments` object নেই। তবে **প্যারামিটার লিস্টের শেষে** ডিফল্ট মান দেওয়া যায় — সেগুলো call site-এ optional হয়ে যায়।

```bnl
function greet(name, greeting = "Hi") {
    return greeting + ", " + name;
}

greet("Alice");           // "Hi, Alice"
greet("Alice", "Hello");  // "Hello, Alice"
// greet();               // error: 1 to 2 arguments expected, got 0
```

ডিফল্টের নিয়ম:

- ডিফল্ট অবশ্যই প্যারামিটার লিস্টের **শেষে** থাকতে হবে। `function bad(a = 1, b) {...}` parse error।
- ডিফল্ট এক্সপ্রেশন **প্রতি call-এ lazy** ভাবে evaluate হয়, ফাংশনের local env-এ — তাই পরের ডিফল্ট আগের প্যারামিটার রেফার করতে পারে:

  ```bnl
  function range(start, end = start + 10) {
      return [start, end];
  }
  range(0);     // [0, 10]
  range(100);   // [100, 110]
  ```

সত্যিকারের ভিন্ন intent থাকলে এখনো আলাদা নামের ফাংশনে ভাগ করুন:

```bnl
function greet(name)               { return "Hi, " + name; }
function greet_formal(title, name) { return title + " " + name; }
```

## ক্লোজার

ইনার ফাংশন আউটার ভ্যারিয়েবল রেফারেন্স দিয়ে ক্যাপচার করে:

```bnl
function make_counter() {
    var n = 0;
    return function () {
        n = n + 1;
        return n;
    };
}

var c = make_counter();
print(c());   // 1
print(c());   // 2
```

## রিটার্ন ভ্যালু

`return <expr>;` এক্সপ্রেশনের মান ফেরত দেয়। খালি `return;` (অথবা শেষ পর্যন্ত পৌঁছানো) `null` ফেরত দেয়।

বিস্তারিত [`return`](/bn/docs/v1.0.0/keywords/return-keyword) দেখুন।
