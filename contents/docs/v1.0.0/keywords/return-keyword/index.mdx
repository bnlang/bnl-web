# <I18nEnglish>`return` keyword</I18nEnglish>
# <I18nBangla>`ফেরত` কীওয়ার্ড</I18nBangla>


<I18nEnglish>
`return` ends a function call and yields a value back to the caller. The Bangla form `ফেরত` is equivalent.

## Syntax

```bnl
return <expression>;   // return a value
return;                // return null and exit
```

## Examples

```bnl
function add(a, b) {
    return a + b;
}

print(add(2, 3));   // 5
```

## Early return

A bare `return;` exits the function and yields `null`. Use it as a guard:

```bnl
function pay(amount) {
    if (amount <= 0) {
        print("amount must be positive");
        return;
    }
    print("paying:", amount);
}
```

## Implicit return

If execution falls off the end of a function without `return`, the function returns `null`.

```bnl
function shout(name) {
    print("HEY " + name);
    // no return — implicit null
}

print(shout("Alice"));   // prints "HEY Alice", then "null"
```

## Returning multiple values

Bnlang has no tuple syntax. Return a list or a map:

```bnl
function divmod(a, b) {
    return { q: a / b, r: a % b };
}

var r = divmod(17, 5);
print(r.q, r.r);   // 3 2
```

## Bangla form

```bnl
ফাংশন যোগ(a, b) {
    ফেরত a + b;
}
```
</I18nEnglish>

<I18nBangla>
`return` একটি ফাংশন কল শেষ করে এবং কলারকে একটি মান ফেরত দেয়। বাংলা রূপ `ফেরত` সমার্থক।

## সিনট্যাক্স

```bnl
return <expression>;   // মান ফেরত
return;                // null ফেরত দিয়ে exit
```

## উদাহরণ

```bnl
function add(a, b) {
    return a + b;
}

print(add(2, 3));   // 5
```

## Early return

খালি `return;` ফাংশন থেকে exit করে এবং `null` ফেরত দেয়। গার্ড হিসেবে ব্যবহার করুন:

```bnl
function pay(amount) {
    if (amount <= 0) {
        print("amount must be positive");
        return;
    }
    print("paying:", amount);
}
```

## Implicit return

`return` ছাড়া ফাংশনের শেষে পৌঁছালে ফাংশন `null` ফেরত দেয়।

```bnl
function shout(name) {
    print("HEY " + name);
    // কোনো return নেই — implicit null
}

print(shout("Alice"));   // "HEY Alice" প্রিন্ট, তারপর "null"
```

## একাধিক মান ফেরত

Bnlang-এ tuple সিনট্যাক্স নেই। একটি লিস্ট বা ম্যাপ ফেরত দিন:

```bnl
function divmod(a, b) {
    return { q: a / b, r: a % b };
}

var r = divmod(17, 5);
print(r.q, r.r);   // 3 2
```

## বাংলা রূপ

```bnl
ফাংশন যোগ(a, b) {
    ফেরত a + b;
}
```
