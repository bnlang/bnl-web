<I18nEnglish>
Bnlang ships with a batteries-included standard library — file I/O, HTTP server and client, templating, four database drivers, crypto, WebSockets, and more. Every module on this page is importable out of the box, no installation needed:

```bnl
import "io"   as io;
import "web"  as web;
import "json" as json;
```

Every module also has a **Bangla alias** — `import "ফাইল"`, `import "ওয়েব"`, `import "জেসন"` resolve to the same Module instances. See [Bilingual aliases](/en/docs/v1.0.0/bilingual) for the full mapping.

## Core

| Module | Purpose |
|---|---|
| [`sys`](/en/docs/v1.0.0/modules/sys-module) | Process info — argv, env, cwd, exit. |
| [`io`](/en/docs/v1.0.0/modules/io-module) | File I/O — sync, async, and streaming. |
| [`path`](/en/docs/v1.0.0/modules/path-module) | Cross-platform path manipulation. |
| [`timers`](/en/docs/v1.0.0/modules/timers-module) | `set` / `interval` for deferred and repeated callbacks. |
| [`time`](/en/docs/v1.0.0/modules/time-module) | Clocks, calendar conversion, ISO 8601. |

<I18nBangla>
Bnlang ব্যাটারি-ইনক্লুডেড স্ট্যান্ডার্ড লাইব্রেরি নিয়ে শিপ হয় — ফাইল I/O, HTTP সার্ভার ও ক্লায়েন্ট, টেমপ্লেটিং, চারটি ডাটাবেস ড্রাইভার, ক্রিপ্টো, WebSocket, এবং আরও অনেক কিছু। এই পেজের প্রতিটি মডিউল out of the box ইমপোর্টযোগ্য, কোনো ইনস্টলেশন দরকার নেই:

```bnl
import "io"   as io;
import "web"  as web;
import "json" as json;
```

প্রতিটি মডিউলের একটি **বাংলা alias** আছে — `import "ফাইল"`, `import "ওয়েব"`, `import "জেসন"` একই Module instance-এ resolve হয়। পূর্ণ mapping-এর জন্য [দ্বিভাষিক নাম](/bn/docs/v1.0.0/bilingual) দেখুন।
