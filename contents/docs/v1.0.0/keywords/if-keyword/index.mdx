# <I18nEnglish>`if` keyword</I18nEnglish>
# <I18nBangla>`যদি` কীওয়ার্ড</I18nBangla>


<I18nEnglish>
`if` runs a block when its condition evaluates to `true`. Chain with `else if` and `else` for additional branches. The Bangla form `যদি` is exactly equivalent.

## Syntax

```bnl
if (<condition>) {
    // runs when condition is true
} else if (<another condition>) {
    // runs when the first was false and this is true
} else {
    // runs when nothing above matched
}
```

## Examples

```bnl
var score = 85;

if (score >= 80) {
    print("Grade: A+");
} else if (score >= 70) {
    print("Grade: A");
} else {
    print("Grade: below A");
}
```

Bangla form:

```bnl
চলক নম্বর = 85;

যদি (নম্বর >= 80) {
    print("গ্রেড: A+");
} নাহলে যদি (নম্বর >= 70) {
    print("গ্রেড: A");
} নাহলে {
    print("গ্রেড: A-এর নিচে");
}
```

## Truthiness

Bnlang has *no* JavaScript-style truthiness rules. A condition must evaluate to a **boolean** (`true` / `false`). Compare explicitly:

```bnl
var name = "";

// Correct:
if (name == "") { print("empty"); }

// Wrong — does not coerce string to boolean:
// if (name) { ... }
```

## Early return idiom

For functions, prefer early returns over deeply nested `if`:

```bnl
function pay(amount) {
    if (amount <= 0) {
        print("amount must be positive");
        return;
    }
    print("processing payment:", amount);
}
```
</I18nEnglish>

<I18nBangla>
`if` শর্ত `true` হলে একটি ব্লক চালায়। অতিরিক্ত শাখার জন্য `else if` ও `else` চেইন করুন। বাংলা রূপ `যদি` একই অর্থে কাজ করে।

## সিনট্যাক্স

```bnl
if (<শর্ত>) {
    // সত্য হলে চলে
} else if (<আরেকটি শর্ত>) {
    // প্রথমটি false এবং এটি true হলে
} else {
    // উপরের কিছুই না মিললে
}
```

## উদাহরণ

```bnl
var score = 85;

if (score >= 80) {
    print("Grade: A+");
} else if (score >= 70) {
    print("Grade: A");

    print("Grade: below A");
```

বাংলা রূপ:

```bnl
    print("গ্রেড: A");

    print("গ্রেড: A-এর নিচে");
```

## Truthiness

Bnlang-এ *কোনো* JavaScript-স্টাইলের truthiness নিয়ম নেই। একটি শর্তকে **boolean** (`true` / `false`) এ মূল্যায়ন হতে হবে। স্পষ্টভাবে তুলনা করুন:

```bnl
var name = "";

// সঠিক:
if (name == "") { print("empty"); }

// ভুল — স্ট্রিং বুলিয়ানে কোয়ার্স করে না:
// if (name) { ... }
```

## Early return idiom

ফাংশনের জন্য, গভীর নেস্টেড `if`-এর পরিবর্তে early return পছন্দ করুন:

```bnl
function pay(amount) {
    if (amount <= 0) {
        print("amount must be positive");
        return;
    }
    print("processing payment:", amount);
}
```
