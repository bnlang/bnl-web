# <I18nEnglish>`else` keyword</I18nEnglish>
# <I18nBangla>`নাহলে` কীওয়ার্ড</I18nBangla>


<I18nEnglish>
`else` attaches a fallback branch to an `if`. The Bangla form `নাহলে` is equivalent.

`else` always follows an `if`; it never stands on its own. For multi-way branching, chain `else if`.

## Syntax

```bnl
if (<condition>) {
    // primary branch
} else {
    // runs when the condition was false
}
```

## Examples

```bnl
var is_admin = false;

if (is_admin) {
    print("welcome, admin");
} else {
    print("guest access");
}
```

Bangla:

```bnl
চলক is_admin = false;

যদি (is_admin) {
    print("welcome, admin");
} নাহলে {
    print("guest access");
}
```

## Chained else if

```bnl
var status_code = 404;

if (status_code == 200) {
    print("ok");
} else if (status_code == 404) {
    print("not found");
} else if (status_code >= 500) {
    print("server error");
} else {
    print("other:", status_code);
}
```

<I18nBangla>
`else` একটি `if`-এর সাথে একটি ফলব্যাক শাখা যুক্ত করে। বাংলা রূপ `নাহলে` সমার্থক।

`else` সবসময় একটি `if`-এর পরে আসে; এটি একা দাঁড়ায় না। মাল্টি-ওয়ে ব্রাঞ্চিং-এর জন্য `else if` চেইন করুন।

## সিনট্যাক্স

```bnl
if (<শর্ত>) {
    // প্রাথমিক শাখা
} else {
    // শর্ত false হলে চলে
}
```
