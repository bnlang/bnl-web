# <I18nEnglish>`for` / `of` keywords</I18nEnglish>
# <I18nBangla>`প্রতি` / `এর` কীওয়ার্ড</I18nBangla>


<I18nEnglish>
Bnlang has exactly one form of `for` loop: `for (var <name> of <list>) { ... }`. It binds `<name>` to each element of `<list>` in order. The English form is `for ... of`; the Bangla form is `প্রতি ... এর`.

There is **no** C-style `for (init; test; update)` loop. For counter-driven loops, use `while`.

## Syntax

```bnl
for (var <name> of <list>) {
    // body
}
```

## Examples

```bnl
for (var n of [1, 2, 3, 4, 5]) {
    print(n);
}
```

Bangla form:

```bnl
প্রতি (চলক n এর [1, 2, 3, 4, 5]) {
    print(n);
}
```

## Iterating with an index

If you need the index too, pair `for ... of` with a counter:

```bnl
var items = ["a", "b", "c"];
var i = 0;
for (var item of items) {
    print(i, item);
    i = i + 1;
}
```

## What's *not* here

- **No C-style `for`.** `for (var i = 0; i < n; i++)` is not valid syntax — use `while`.
- **No `for ... in`.** To iterate map keys, use `for (var k of m.keys()) { ... }`.

## Early exit and skip

Use [`break`](/en/docs/v1.0.0/keywords/break-keyword) to exit the loop and [`continue`](/en/docs/v1.0.0/keywords/continue-keyword) to skip to the next item:

```bnl
for (var n of [1, 2, 3, 4, 5]) {
    if (n == 4) { break; }
    if (n == 2) { continue; }
    print(n);
}
// 1
// 3
```

## See also
- [`while`](/en/docs/v1.0.0/keywords/while-keyword) — for counter-driven or condition-driven loops.
</I18nEnglish>

<I18nBangla>
Bnlang-এ ঠিক একটি `for` লুপ রূপ আছে: `for (var <name> of <list>) { ... }`। এটি `<name>`-কে `<list>`-এর প্রতিটি উপাদানে ক্রমে বাইন্ড করে। ইংরেজি রূপ `for ... of`; বাংলা রূপ `প্রতি ... এর`।

C-স্টাইলের `for (init; test; update)` লুপ **নেই**। কাউন্টার-চালিত লুপের জন্য `while` ব্যবহার করুন।

## সিনট্যাক্স

```bnl
for (var <name> of <list>) {
    // body
}
```

## উদাহরণ

```bnl
for (var n of [1, 2, 3, 4, 5]) {
    print(n);
}
```

বাংলা রূপ:

```bnl
প্রতি (চলক n এর [1, 2, 3, 4, 5]) {
    print(n);
}
```

## ইনডেক্স সহ ইটারেট

ইনডেক্স দরকার হলে `for ... of`-এর সাথে একটি কাউন্টার পেয়ার করুন:

```bnl
var items = ["a", "b", "c"];
var i = 0;
for (var item of items) {
    print(i, item);
    i = i + 1;
}
```

## যা *এখানে নেই*

- **কোনো C-স্টাইল `for` নেই।** `for (var i = 0; i < n; i++)` ভ্যালিড সিনট্যাক্স নয় — `while` ব্যবহার করুন।
- **কোনো `for ... in` নেই।** ম্যাপ কী ইটারেট করতে `for (var k of m.keys()) { ... }` ব্যবহার করুন।

## Early exit ও skip

Loop থেকে exit করতে [`break`](/bn/docs/v1.0.0/keywords/break-keyword) এবং পরের item-এ skip করতে [`continue`](/bn/docs/v1.0.0/keywords/continue-keyword) ব্যবহার করুন:

```bnl
for (var n of [1, 2, 3, 4, 5]) {
    if (n == 4) { break; }
    if (n == 2) { continue; }
    print(n);
}
// 1
// 3
```

## আরও দেখুন
- [`while`](/bn/docs/v1.0.0/keywords/while-keyword) — কাউন্টার বা শর্ত-চালিত লুপের জন্য।
</I18nBangla>
