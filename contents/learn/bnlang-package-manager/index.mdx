# <I18nEnglish>Bnlang Package Manager (BPM)</I18nEnglish>
# <I18nBangla>Bnlang প্যাকেজ ম্যানেজার (BPM)</I18nBangla>

<I18nEnglish>
**BPM** is the official package manager for Bnlang. It manages two files in your project:

- **`bnl.json`** — the project manifest: name, version, dependencies, main entry point.
- **`bnl.lock`** — a generated lockfile pinning every direct and transitive dependency to a concrete version + integrity hash.

Packages install into a local `./deps/` folder by default (or `~/.bnl/deps` with `-g`).
</I18nEnglish>

<I18nBangla>
**BPM** Bnlang-এর অফিসিয়াল প্যাকেজ ম্যানেজার। এটি আপনার প্রজেক্টে দু'টি ফাইল ম্যানেজ করে:

- **`bnl.json`** — প্রজেক্ট ম্যানিফেস্ট: নাম, সংস্করণ, ডিপেন্ডেন্সি, মেইন এন্ট্রি পয়েন্ট।
- **`bnl.lock`** — জেনারেটেড লকফাইল, যা প্রতিটি ডাইরেক্ট ও ট্রানজিটিভ ডিপেন্ডেন্সিকে একটি কংক্রিট সংস্করণ + integrity হ্যাশে পিন করে।

প্যাকেজ ডিফল্টভাবে লোকাল `./deps/` ফোল্ডারে ইনস্টল হয় (অথবা `-g` দিয়ে `~/.bnl/deps`-এ)।
</I18nBangla>

## Installing BPM

<I18nEnglish>
BPM ships alongside Bnlang. Confirm with:
</I18nEnglish>

<I18nBangla>

## Example Workflow

```sh
# Start a new project
mkdir my-app && cd my-app
bpm init

# Add a dependency
bpm install some-package

# Or install everything from bnl.json (e.g. on a fresh checkout)
bpm install

# Remove what you don't need anymore
bpm uninstall some-package

# Publish your own package
bpm login
bpm publish
```

## Using an Installed Package

<I18nEnglish>
Installed packages live under `./deps/`. Import them by name — the import resolver knows where to look.
</I18nEnglish>

<I18nBangla>
ইনস্টল করা প্যাকেজ `./deps/`-এ থাকে। নাম দিয়ে ইমপোর্ট করুন — ইমপোর্ট রিজলভার জানে কোথায় খুঁজতে হবে।
</I18nBangla>

```bnl
import "some-package" as pkg;

print(pkg.hello());
```

## Best Practices

<I18nEnglish>
- Commit both <code>bnl.json</code> and <code>bnl.lock</code>. The lockfile is what makes other people's installs reproduce yours.
- Use semantic version ranges (<code>^1.2.3</code>) in <code>bnl.json</code> for direct deps so patch releases flow in naturally.
- Use <code>-g</code> sparingly — global installs are great for CLIs you want on PATH, less great for app dependencies.
- Give packages clear, lowercase names and document the public API in a README.
</I18nEnglish>

<I18nBangla>
- <code>bnl.json</code> এবং <code>bnl.lock</code> দু'টোই কমিট করুন। লকফাইলই অন্যদের ইনস্টলকে আপনার সাথে রিপ্রোডিউস করায়।
- ডাইরেক্ট ডিপের জন্য <code>bnl.json</code>-এ সেমান্টিক সংস্করণ রেঞ্জ (<code>^1.2.3</code>) ব্যবহার করুন, যাতে patch রিলিজ স্বাভাবিকভাবে আসে।
- <code>-g</code> পরিমিত ব্যবহার করুন — গ্লোবাল ইনস্টল PATH-এ থাকা CLI-এর জন্য ভালো, অ্যাপ ডিপেন্ডেন্সির জন্য তেমন না।
- প্যাকেজকে পরিষ্কার, ছোট-হাতের নাম দিন এবং README-তে পাবলিক API ডকুমেন্ট করুন।
</I18nBangla>
