# <I18nEnglish>`break` keyword</I18nEnglish>
# <I18nBangla>`থামুন` কীওয়ার্ড</I18nBangla>


<I18nEnglish>
`break;` exits the nearest enclosing `while`, `for`, `for ... of`, or `switch`. Bangla form: `থামুন;`.

## Syntax

```bnl
break;
```

## Examples

Exit a loop early when a condition is hit:

```bnl
for (var n of [1, 2, 3, 4, 5]) {
    if (n == 3) { break; }
    print(n);
}
// 1
// 2
```

Exit a `switch` case explicitly (rare — the case body already ends naturally):

```bnl
switch (status) {
    case "ready": {
        do_work();
        break;          // optional; falling off the end has the same effect
    }
    default: { print("not ready"); }
}
```

## Nested loops

`break` exits the **innermost** enclosing loop or switch only:

```bnl
for (var i of [1, 2, 3]) {
    for (var j of [10, 20, 30]) {
        if (j == 20) { break; }   // exits the inner for-of, not the outer one
        print(i, j);
    }
}
// 1 10
// 2 10
// 3 10
```

For multi-level exits, use a sentinel variable in the outer loop's condition.

## Bangla form

```bnl
যতক্ষণ (i < 10) {
    যদি (i == 5) { থামুন; }
    print(i);
    i = i + 1;
}
```

<I18nBangla>
`break;` নিকটতম enclosing `while`, `for`, `for ... of`, বা `switch` থেকে exit করে। বাংলা রূপ: `থামুন;`।

## সিনট্যাক্স

```bnl
break;
```

## উদাহরণ

একটি শর্ত পূরণ হলে loop থেকে তাড়াতাড়ি বের হোন:

```bnl
for (var n of [1, 2, 3, 4, 5]) {
    if (n == 3) { break; }
    print(n);
}
// 1
// 2
```

একটি `switch` case থেকে explicit exit (বিরল — case body স্বাভাবিকভাবেই শেষ হয়):

```bnl
switch (status) {
    case "ready": {
        do_work();
        break;          // ঐচ্ছিক
    }
    default: { print("not ready"); }
}
```

## Nested loops

`break` শুধু **সবচেয়ে ভেতরের** enclosing loop বা switch থেকে exit করে:

```bnl
for (var i of [1, 2, 3]) {
    for (var j of [10, 20, 30]) {
        if (j == 20) { break; }   // inner for-of থেকে exit, outer নয়
        print(i, j);
    }
}
```

মাল্টি-লেভেল exit-এর জন্য outer loop-এর condition-এ একটি sentinel ভ্যারিয়েবল ব্যবহার করুন।

## বাংলা রূপ

```bnl
যতক্ষণ (i < 10) {
    যদি (i == 5) { থামুন; }
    print(i);
    i = i + 1;
}
```
