# <I18nEnglish>Reading Files in Bnlang</I18nEnglish>
# <I18nBangla>Bnlang এ ফাইল পড়া</I18nBangla>


<I18nEnglish>
Reading files is one of the most common things a program does.
The built-in `io` module gives you three flavors, from simplest to most powerful:

- `io.read_file(path)` — synchronous; returns the whole file as a string.
- `io.read_file_async(path, cb)` — asynchronous; the callback receives the data when ready.
- `io.open_read(path)` — streaming; pull the file in chunks for memory-friendly processing.
</I18nEnglish>

<I18nBangla>
ফাইল পড়া প্রোগ্রামের সবচেয়ে সাধারণ কাজের মধ্যে একটি।
বিল্ট-ইন `io` মডিউল তিনটি ফ্লেভার দেয়, সরল থেকে শক্তিশালী:

- `io.read_file(path)` — সিঙ্ক্রোনাস; পুরো ফাইল স্ট্রিং হিসেবে ফেরত দেয়।
- `io.read_file_async(path, cb)` — অ্যাসিঙ্ক্রোনাস; ডাটা প্রস্তুত হলে কলব্যাক পায়।
- `io.open_read(path)` — স্ট্রিমিং; মেমরি-ফ্রেন্ডলি প্রসেসিং-এর জন্য ফাইল চাঙ্কে পুল করুন।
</I18nBangla>



---

## Synchronous Read

<I18nEnglish>
The simplest form. Blocks the event loop until the whole file is in memory. Use this in scripts and for small files.
</I18nEnglish>

<I18nBangla>
সরলতম ফর্ম। পুরো ফাইল মেমরিতে আসা পর্যন্ত ইভেন্ট লুপ ব্লক করে। স্ক্রিপ্ট এবং ছোট ফাইলের জন্য ব্যবহার করুন।
</I18nBangla>

```bnl
import "io" as io;

var text = io.read_file("notes.txt");
print(text);
```

---

## Asynchronous Read

<I18nEnglish>
Returns immediately. The callback is invoked once the read completes — first argument is the error (or `null`), second is the file contents.
</I18nEnglish>

<I18nBangla>
সাথে সাথে ফেরত আসে। পড়া শেষ হলে কলব্যাক ইনভোক হয় — প্রথম আর্গুমেন্ট এরর (বা `null`), দ্বিতীয়টি ফাইল কনটেন্ট।
</I18nBangla>

```bnl
import "io" as io;

io.read_file_async("notes.txt", function (err, data) {
    if (err != null) {
        print("read failed:", err);
        return;
    }
    print("got", data.byte_length, "bytes");
});
print("scheduled — keep doing other work");
```

## Streaming Large Files

<I18nEnglish>
For files that don't fit comfortably in memory, open a read stream and pull chunks. The callback receives `chunk = null` to signal **EOF**.
</I18nEnglish>

<I18nBangla>
যেসব ফাইল আরামে মেমরিতে আঁটে না, রিড স্ট্রিম খুলুন এবং চাঙ্ক পুল করুন। কলব্যাকে `chunk = null` মানে **EOF**।
</I18nBangla>

```bnl
import "io" as io;

var src   = io.open_read("big.log");
var total = 0;

function on_chunk(err, chunk) {
    if (err != null) { print("read err:", err); src.close(); return; }
    if (chunk == null) {
        print("done. total:", total, "bytes");
        src.close();
        return;
    }
    total = total + chunk.byte_length;
    src.read(64 * 1024, on_chunk);
}

src.read(64 * 1024, on_chunk);
```

## Best Practices

<I18nEnglish>
- Reach for `io.read_file_async` by default in long-running programs (servers, daemons).
- Use the sync variant for one-shot scripts where simplicity wins.
- For files larger than, say, a few megabytes, prefer `io.open_read` so you don't allocate a huge string.
- Always call `src.close()` when you're done with a stream — otherwise the OS file handle stays open.
</I18nEnglish>

<I18nBangla>
- দীর্ঘ-চলা প্রোগ্রামে (সার্ভার, ডিমন) ডিফল্ট হিসেবে `io.read_file_async` ব্যবহার করুন।
- একবারের স্ক্রিপ্ট, যেখানে সহজতা গুরুত্বপূর্ণ — sync ভ্যারিয়েন্ট ব্যবহার করুন।
- কয়েক মেগাবাইটের চেয়ে বড় ফাইলের জন্য `io.open_read` ব্যবহার করুন, যাতে বিশাল স্ট্রিং অ্যালোকেট না হয়।
- স্ট্রিম শেষ হলে সবসময় `src.close()` কল করুন — না করলে OS ফাইল হ্যান্ডেল খোলা থাকবে।
</I18nBangla>
