# <I18nEnglish>`while` keyword</I18nEnglish>
# <I18nBangla>`যতক্ষণ` কীওয়ার্ড</I18nBangla>


<I18nEnglish>
`while` runs its body repeatedly as long as its condition is `true`. The Bangla form `যতক্ষণ` is equivalent.

The condition is re-evaluated **before** each iteration. If it starts out `false`, the body runs zero times.

## Syntax

```bnl
while (<condition>) {
    // body
}
```

## Examples

A counted loop (replaces C-style `for`):

```bnl
var i = 0;
while (i < 5) {
    print("tick", i);
    i = i + 1;
}
```

Bangla form:

```bnl
চলক i = 0;
যতক্ষণ (i < 5) {
    print("tick", i);
    i = i + 1;
}
```

## Early exit and skip

Use [`break`](/en/docs/v1.0.0/keywords/break-keyword) to exit the loop and [`continue`](/en/docs/v1.0.0/keywords/continue-keyword) to skip to the next iteration:

```bnl
var i = 0;
while (i < 10) {
    i = i + 1;
    if (i == 7) { break; }
    if (i % 2 == 0) { continue; }
    print(i);
}
// 1
// 3
// 5
```

## See also
- [`for / of`](/en/docs/v1.0.0/keywords/for-keyword) — when you have a list to iterate.
</I18nEnglish>

<I18nBangla>
`while` তার body বারবার চালায় যতক্ষণ শর্ত `true`। বাংলা রূপ `যতক্ষণ` সমার্থক।

প্রতিটি iteration-এর **আগে** শর্ত পুনরায় মূল্যায়িত হয়। যদি প্রথমেই `false` থাকে, body কখনোই চলে না।

## সিনট্যাক্স

```bnl
while (<শর্ত>) {
    // body
}
```

## উদাহরণ

একটি কাউন্টেড লুপ (C-স্টাইল `for`-এর বদলে):

```bnl
var i = 0;
while (i < 5) {
    print("tick", i);
    i = i + 1;
}
```

বাংলা রূপ:

```bnl
চলক i = 0;
যতক্ষণ (i < 5) {
    print("tick", i);
    i = i + 1;
}
```

## Early exit ও skip

Loop থেকে exit করতে [`break`](/bn/docs/v1.0.0/keywords/break-keyword) এবং পরের iteration-এ skip করতে [`continue`](/bn/docs/v1.0.0/keywords/continue-keyword) ব্যবহার করুন:

```bnl
var i = 0;
while (i < 10) {
    i = i + 1;
    if (i == 7) { break; }
    if (i % 2 == 0) { continue; }
    print(i);
}
// 1
// 3
// 5
```
