# <I18nEnglish>`io` module</I18nEnglish>
# <I18nBangla>`io` মডিউল</I18nBangla>


<I18nEnglish>
File and directory primitives. Every blocking call has an async counterpart (`*_async`); for very large files use the streaming `open_read` / `open_write`.

```bnl
import "io" as io;

io.write_file("greeting.txt", "Hello!");
print(io.read_file("greeting.txt"));
```

## Sync file I/O

| Function | Description |
|---|---|
| `io.read_file(path)` → string | Read the whole file into a string. |
| `io.write_file(path, data)` | Overwrite the file with `data`. |
| `io.append_file(path, data)` | Append `data`; creates the file if missing. |

## Async file I/O

`*_async` functions return a [`Future`](/en/docs/v1.0.0/modules/future-module) — pair with `wait`.

| Function | Description |
|---|---|
| `io.read_file_async(path)` → Future&lt;string&gt; | Read off the main thread; suitable for large files. |
| `io.write_file_async(path, data)` → Future&lt;null&gt; | Write off the main thread. |

```bnl
function copy() {
    var data = wait io.read_file_async("big.bin");
    wait io.write_file_async("big.copy.bin", data);
}
```

## Streaming

`open_read` / `open_write` return a stream object whose `read` / `write` are themselves Future-returning. The underlying callback-style methods are still available on the native `_io` module for low-level code.

| Function | Description |
|---|---|
| `io.open_read(path)` → stream | `stream.read(size)` returns `Future<chunk>`; `chunk == null` means EOF. `stream.close()` is sync. |
| `io.open_write(path)` → stream | `stream.write(data)` returns `Future<null>`. `stream.close()` is sync — call it to flush. |

```bnl
function read_chunks(path) {
    var src = io.open_read(path);
    var chunk = wait src.read(4096);
    while (chunk != null) {
        print(chunk);
        chunk = wait src.read(4096);
    }
    src.close();
}
```

## Native `_io` (advanced)

The native module is also available as `_io` for low-level callback-style code (used by the lib internally). User code should prefer `import "io"`.

## Metadata

| Function | Description |
|---|---|
| `io.exists(path)` → bool | True if the path exists. |
| `io.is_file(path)` → bool | |
| `io.is_dir(path)` → bool | |
| `io.stat(path)` → map | `{bytes, mtime, is_file, is_dir}`. Throws if missing. |

## Directories

| Function | Description |
|---|---|
| `io.mkdir(path)` | Creates intermediate parents automatically. |
| `io.list_dir(path)` → list | Entry names (no `.` / `..`). |
| `io.remove(path)` | File or directory; **recursive** for directories. |
| `io.rename(from, to)` | |
| `io.copy_file(from, to)` | |

<I18nBangla>
ফাইল ও ডিরেক্টরি প্রিমিটিভ। প্রতিটি blocking কলের একটি async counterpart (`*_async`) আছে; খুব বড় ফাইলের জন্য streaming `open_read` / `open_write` ব্যবহার করুন।

```bnl
import "io" as io;

io.write_file("greeting.txt", "Hello!");
print(io.read_file("greeting.txt"));
```

## Sync ফাইল I/O

| ফাংশন | বর্ণনা |
|---|---|
| `io.read_file(path)` → string | পুরো ফাইল একটি স্ট্রিং-এ পড়ুন। |
| `io.write_file(path, data)` | ফাইল `data` দিয়ে ওভাররাইট করুন। |
| `io.append_file(path, data)` | `data` অ্যাপেন্ড; না থাকলে তৈরি। |

## Async ফাইল I/O

`*_async` ফাংশন একটি [`Future`](/bn/docs/v1.0.0/modules/future-module) ফেরত দেয় — `wait`-এর সাথে ব্যবহার করুন।

| ফাংশন | বর্ণনা |
|---|---|
| `io.read_file_async(path)` → Future&lt;string&gt; | Main thread-এর বাইরে পড়ে; বড় ফাইলের জন্য। |
| `io.write_file_async(path, data)` → Future&lt;null&gt; | Main thread-এর বাইরে লেখে। |

```bnl
function copy() {
    var data = wait io.read_file_async("big.bin");
    wait io.write_file_async("big.copy.bin", data);
}
```

## Streaming

`open_read` / `open_write` এমন stream ফেরত দেয় যার `read` / `write` নিজেও Future-returning। নিচু-স্তরের কোডের জন্য callback-style পদ্ধতিগুলো native `_io` module-এ এখনো পাওয়া যায়।

| ফাংশন | বর্ণনা |
|---|---|
| `io.open_read(path)` → stream | `stream.read(size)` → `Future<chunk>`; `chunk == null` মানে EOF। `stream.close()` sync। |
| `io.open_write(path)` → stream | `stream.write(data)` → `Future<null>`। `stream.close()` sync — flush-এর জন্য কল করুন। |

## Native `_io` (advanced)

Native module-টা `_io` নামেও উপলব্ধ — নিচু-স্তরের callback-style কোডের জন্য (lib ভেতরে এটা ব্যবহার করে)। সাধারণত `import "io"` ব্যবহার করুন।

| ফাংশন | বর্ণনা |
|---|---|
| `io.exists(path)` → bool | পাথ থাকলে true। |
| `io.is_file(path)` → bool | |

| `io.stat(path)` → map | `{bytes, mtime, is_file, is_dir}`। অনুপস্থিত হলে throw। |

|---|---|

| `io.list_dir(path)` → list | এন্ট্রি নাম (কোনো `.` / `..` নেই)। |
| `io.remove(path)` | ফাইল বা ডিরেক্টরি; ডিরেক্টরির জন্য **recursive**। |
| `io.rename(from, to)` | |
| `io.copy_file(from, to)` | |
