<I18nEnglish>
The simplest way to write to the terminal is the built-in `print` function — it accepts any number of arguments, separates them with spaces, and adds a trailing newline.

</I18nEnglish>

<I18nBangla>
টার্মিনালে লেখার সবচেয়ে সরল উপায় হলো বিল্ট-ইন `print` ফাংশন — এটি যে কোনো সংখ্যক আর্গুমেন্ট নেয়, স্পেস দিয়ে আলাদা করে, এবং একটি নতুন লাইন যোগ করে।
দ্রুত স্ক্রিপ্টের বাইরে যেকোনো কিছুর জন্য `log` লাইব্রেরি ব্যবহার করুন, যা সিভিয়ারিটি লেভেল এবং কনফিগারেবল সিঙ্ক যোগ করে।
</I18nBangla>

<I18nBangla>

## The log Library — Levels and Structure

<I18nEnglish>
For real programs you want severity (info vs warning vs error), timestamps, and a single place to redirect output. The `log` library handles all three.
</I18nEnglish>

<I18nBangla>
বাস্তব প্রোগ্রামের জন্য আপনি সিভিয়ারিটি (info vs warning vs error), টাইমস্ট্যাম্প, এবং আউটপুট রিডাইরেক্ট করার একটি জায়গা চান। `log` লাইব্রেরি তিনটাই সামলায়।
</I18nBangla>

```bnl
import "log" as log;

log.info("server starting");
log.warn("port", 3000, "already in use, falling back");
log.error("could not bind, exiting");
```

## Writing to stderr

<I18nEnglish>
`print` writes to standard output. Errors usually belong on **stderr** so they aren't captured into your data pipeline. Use `sys.write_err`:
</I18nEnglish>

<I18nBangla>
`print` standard output-এ লেখে। এররগুলো সাধারণত **stderr**-এ থাকা উচিত যাতে আপনার ডাটা পাইপলাইনে ক্যাপচার না হয়। `sys.write_err` ব্যবহার করুন:
</I18nBangla>

```bnl
import "sys" as sys;

sys.write_err("something went wrong\n");
```

## Best Practices

<I18nEnglish>
- Use `print` freely while prototyping; switch to the `log` library before deploying.
- Send anything that isn't program output (warnings, errors, progress) to stderr so callers can pipe stdout cleanly.
- Don't log secrets — API keys, tokens, passwords — even at debug level.
</I18nEnglish>

<I18nBangla>
- প্রোটোটাইপিং-এর সময় `print` মুক্তভাবে ব্যবহার করুন; ডিপ্লয় করার আগে `log` লাইব্রেরিতে শিফট করুন।
- যা প্রোগ্রাম আউটপুট নয় (ওয়ার্নিং, এরর, প্রোগ্রেস) সেগুলো stderr-এ পাঠান, যাতে কলার stdout পরিষ্কারভাবে পাইপ করতে পারে।
- সিক্রেট লগ করবেন না — API key, টোকেন, পাসওয়ার্ড — এমনকি ডিবাগ লেভেলেও না।
</I18nBangla>
